# 搬到另一台机器（部署清单）

本项目**不是为某一台电脑定制的**：桥的端口/目标/凭据都是运行时发现或可配置的，App 的服务器地址来自扫码或手填。
下面是换机器时需要你知道的全部内容。

## 1. 电脑端（Windows / macOS / Linux 都行，Node ≥ 18）

```bash
# 启动桥：默认监听 0.0.0.0:8099，转发到 127.0.0.1:3080
node share/dsh-mobile-bridge/bridge.cjs
# 换端口 / 换上游：
#   --port 8099 --target http://127.0.0.1:3080
#   DSH_BRIDGE_PORT / DSH_BRIDGE_TARGET 环境变量同理
```

| 项 | 说明 |
| --- | --- |
| 认证凭据 | 自动读 `~/.dsh/.credentials.yaml`（可用 `DSH_HOME` 或 `DSH_BRIDGE_CREDENTIALS` 指定） |
| 设备台账 | 桥目录下的 `device-settings.json`（**不要**从别的机器拷贝，里面有那台机器的设备与口令） |
| 防火墙 | 管理员运行 `allow-firewall.ps1`（自动把本机所在网段加进规则）；或在系统防火墙里放行桥端口 |
| harness 来源栅栏 | 桌面启动器会自动带上 `--trusted-host <本机IP>:<桥端口>`；手动跑 `dsh web` 的话需要自己加 |

## 2. 手机端

- 装 `dsh-mobile-app/dist/dsh-mobile-*.apk`（自签名，**换机器要重新生成签名才能覆盖安装**）；
- 服务器地址：App 首次启动会直接进设置页，扫电脑上「设置 → 手机端」的二维码即可；**没有内置默认地址**。

## 3. 外网访问（可选）

任何 frp / 内网穿透都行，桥不绑定厂商：

1. 隧道指向 `127.0.0.1:8099`（HTTPS 建站隧道要开「自动 HTTPS」，因为桥只提供 HTTP）；
2. 域名 CNAME 指向隧道节点；
3. 证书：怎么签发、要不要续期，由你的部署自己决定——公网 CA 或自签都行（用自签时，App 首次连接会弹出指纹让你核对并记住）；
4. 面板里填外网地址 → 生成二维码 → 手机扫一次。

## 4. 与环境无关的部分（可放心复用）

- 移动端适配注入、手机端面板、按设备隔离的外观/字号/语言；
- 设备指纹与认证流程（粗粒度机型特征 + 可选 Android ID）；
- 传输优化（压缩透传 + brotli + 直接 IP 与隧道同样生效）；
- 抗更新防护（注入前清单自检 + `/__selftest` + 启动器自动回退官方端口）。
